## Hello 👋

I live somewhere between **linguistics, mathematics and code**.

I'm into how language is built and how the brain parses it: generative syntax, formal language theory, corpus linguistics and neurosyntax. I like poking at those questions with code: grammars, parsers, a bit of algebra and, lately, language models.

> *Me interesa cómo está hecho el lenguaje y cómo lo procesa el cerebro. Aquí lo cuento con código.*

### 🌳 What I'm working on

- **Syntactic ambiguity & Catalan numbers**: why *"I saw the man with the telescope in the park…"* has 742,900 possible parses once you add enough prepositional phrases *(coming soon)*
- **Spanish clitics as a regular language**: automata and syntactic monoids for *se te lo* and friends *(coming soon)*
- **Spanish minimal pairs for LLMs**: do language models actually know Spanish syntax? *(coming soon)*

### 🛠️ Things I've built

- [**Qualitune**](https://github.com/jcherrerosl/qualitune_cli): automated audio-quality analysis for music curation (loudness, true peak, clipping, noise, tuning). Python + librosa.
- [**Lógica, conjuntos y números**](https://github.com/jcherrerosl/logica-conjuntos-y-numeros): notes on logic, set theory and number theory, with examples in C *(in Spanish)*.
- [**cub3D**](https://github.com/jcherrerosl/cub3D): a raycasting 3D engine written from scratch in C.
